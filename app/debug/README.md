# 공개 개발용 디버그 서명

`sing-debug.p12`는 이 공개 저장소의 **개발·테스트용으로만 사용하는 공개 키 저장소**입니다. 사용자 비밀이나 프로덕션 서명 키가 아닙니다. Android 디버그 기본 암호/별칭을 사용하며 Gradle의 debug 빌드에만 연결합니다. release/스토어 배포에 사용하지 마세요.

CI 실행마다 다른 임시 키를 생성하면 새 APK를 덮어 설치할 수 없어 앱 삭제 시 로컬 기록이 사라집니다. 이 파일을 재사용해 이후 디버그 빌드 간 업데이트 서명을 유지합니다. 이전 1.0 APK의 임시 키와는 다르므로 이미 설치한 1.0과의 서명 연속성을 복구하지는 못합니다.
