# Sing – 음치탈출 4주

낮은 남성 음역부터 시작하는 **오프라인 Android 노래 연습 앱**입니다. Kotlin, Jetpack Compose, AudioRecord, AudioTrack으로 구현했습니다. Android 8.0(API 26) 이상에서 실행합니다.

## 설치

1. [GitHub Actions](https://github.com/JungdongBae/sing/actions/workflows/android.yml)에서 초록색으로 성공한 최신 실행을 엽니다. GitHub 로그인이 필요할 수 있습니다.
2. 실행 하단의 **Artifacts → sing-debug-apk**를 다운로드하고 ZIP을 풉니다.
3. Android 기기로 `app-debug.apk`를 옮겨 엽니다. 파일 관리자 또는 브라우저의 ‘알 수 없는 앱 설치’를 허용하면 설치할 수 있습니다.

APK는 디버그 서명된 설치용 빌드입니다. 스토어 배포용 서명은 포함하지 않습니다. Artifact는 30일 보관되며, 브랜치 push/PR/수동 실행에서 다시 빌드합니다. 최초 PR 워크플로에 GitHub 승인이 필요한 경우 저장소 Actions 화면에서 승인해 주세요.

## 사용 방법

- **오늘**: 4주 프로그램을 확인하고 하루 20분 타이머를 시작합니다. 2분 준비 + 6~8분씩 두 가지 핵심 연습 + 4분 마무리로 구성됩니다. 단계가 바뀌면 현재 할 일과 연습 도구 버튼이 바뀝니다. 주차는 기본적으로 누적 완료일을 기준으로 선택되며 타이머가 멈춘 상태에서 다른 주차를 선택할 수 있습니다.
- **음정**: 목표음은 기본 C3(130.81 Hz), E2~C4에서 반음 단위로 변경합니다. 기준음을 듣고 마이크를 켠 뒤 편안하게 허밍합니다. 현재 음 이름, Hz와 **선택한 목표음 대비** cents를 확인하세요. ±25 cents를 초록으로 표시합니다. 실제 옥타브 차이도 ±1200 cents로 표시합니다.
- **듣기**: 낮은 음역의 두 음을 듣고 두 번째 음이 높은지 낮은지 답합니다. 정답을 보기 전 음 이름을 숨기며 다시 듣기와 다음 문제를 제공합니다.
- **박자**: 50~120 BPM으로 4박자를 반복합니다. 첫 박의 클릭을 강조합니다. 클릭과 동시에 버튼을 누르면 가장 가까운 박 대비 빠름·늦음(ms)을 표시합니다.
- **곡**: 8박 패턴 또는 퍼블릭 도메인인 「작은별」 전체 48박(C3~A3)을 듣고 연습합니다. 따라 부르기는 클릭만 재생하고 재생 위치에 따라 목표음을 바꾸면서 마이크 음정을 표시합니다. 클릭 유입을 줄이려면 이어폰을 사용하세요.
- **기록**: 날짜별 누적 연습 시간과 20분 완료 기록을 확인합니다. 타이머는 사용자가 시작해야 진행됩니다. 다른 도구로 이동해도 타이머가 계속되며, 앱이 배경으로 이동하면 멈춥니다. 20분을 채우면 자동 완료되고 하루 동안 중복 완료는 만들지 않습니다. 미완료 시간도 재시작 후 이어집니다.

## 개인정보와 오디오 처리

- 마이크 권한은 음정 측정 또는 따라 부르기를 누를 때만 요청합니다. 거부해도 기준음·귀 훈련·메트로놈·타이머를 사용할 수 있습니다. 영구 거부 시 앱 권한 설정을 열 수 있습니다.
- 인터넷 권한, 서버, 분석 SDK, 녹음 파일을 사용하지 않습니다. PCM은 메모리에서 분석하고 버립니다. 연습 날짜·시간, 목표음·BPM만 SharedPreferences에 저장합니다. Android 자동 백업을 끕니다. 앱 삭제 또는 데이터 삭제 시 기록이 사라집니다.
- 배경 이동, 오디오 포커스 상실, 사용자 중지 시 AudioRecord와 AudioTrack을 중지하고 코루틴에서 안전하게 해제합니다. Activity 재생성에도 ViewModel이 상태를 유지합니다.
- 입력은 22,050 Hz 우선, 지원하지 않으면 44,100/48,000 Hz로 대체합니다. YIN의 정규화 차분과 첫 주기 최소점, DC 제거, RMS 게이트, 신뢰도 임계값, 포물선 보간, 3프레임 중앙값을 사용합니다. 분석 범위는 약 65~500 Hz입니다.
- 목표음에 가까워 보이게 옥타브를 접지 않습니다. 일시적 옥타브 튐은 중앙값으로 줄이되 지속된 실제 옥타브 이동은 그대로 표시합니다. 배경의 주기적 소리, 약한 기본음, 큰 반주에서는 잘못 감지할 수 있습니다. 조용한 곳에서 한 음을 유지하세요. 음정 표시는 약 0.2~0.3초 지연될 수 있습니다.
- 메트로놈은 AudioTrack의 네이티브 PCM 루프를 사용합니다. 화면 박자는 playback head 기준입니다. 탭 피드백은 기기 출력·터치 지연까지 보정한 전문 측정값은 아닙니다. Bluetooth보다 스피커 또는 유선 이어폰을 권장합니다.

## 개발과 검증

JDK 17, Android SDK 35가 필요합니다. Android Studio에서 열거나 `local.properties`에 SDK 경로를 설정하고 실행하세요. Gradle 8.10.2 공식 wrapper JAR과 배포 ZIP SHA-256 검증을 포함합니다.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

GitHub Actions에서도 같은 명령으로 단위 테스트, Android lint, APK 생성을 실행하고 APK와 검사 보고서를 업로드합니다. 단위 테스트는 저음 순음·강한 2차 배음·잡음/DC·무음·샘플레이트 대체, 옥타브 안정화, 목표음 기준 cents, 높낮이 문제, 박자 오차, 4주/20분 단계와 전체 곡을 검증합니다.

실기기 확인 항목은 [docs/DEVICE_CHECKLIST.md](docs/DEVICE_CHECKLIST.md)를 참고하세요. 실제 마이크·출력 지연·기기별 권한 동작은 JVM 단위 테스트만으로 검증할 수 없습니다.

## 구조

`core/`는 Android와 분리한 음정·음악·훈련 로직, `audio/`는 입력과 PCM 재생, `data/`는 로컬 기록, `SingViewModel`은 코루틴과 상태, `ui/`는 한국어 Compose 화면입니다.
