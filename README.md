# Sing – 음치탈출 4주

낮은 남성 음역부터 시작하는 **오프라인 Android 노래 연습 앱**입니다. Kotlin, Jetpack Compose, AudioRecord, AudioTrack으로 구현했습니다. Android 8.0(API 26) 이상에서 실행합니다.

## 1.1 개인 맞춤 음역 진단

첫 실행 시 **편안한 음역 찾기**를 안내합니다. ‘나중에 하기’를 선택하면 기존 연습 기능을 사용할 수 있고, 상단 **음역 · 설정** 또는 오늘 화면에서 언제든 다시 진단할 수 있습니다. 기존 20분 연습 기록과 목표음/BPM 설정을 유지합니다.

1. **시작음**: 평소 말하듯 ‘아~’ 소리를 3초간 냅니다. 안정적인 입력의 중앙값으로 Hz와 음 이름을 표시합니다. 같은 편안한 소리를 두 번 측정하고 각각 ‘편안함’을 확인해야 시작음이 정해집니다.
2. **최저 편안음**: 시작음보다 반음 낮은 기준음을 듣고 측정합니다. 각 목표음을 두 번 안정적으로 재현하고 두 번 모두 ‘편안함’을 선택해야 포함합니다. ‘어려움’을 누르면 미확인 음을 제외하고 높은 음 측정으로 넘어갑니다.
3. **최고 편안음**: 시작음보다 반음 높은 음부터 같은 방식으로 확인합니다. ‘어려움’을 누르면 마지막으로 반복 확인한 최고음까지 결과에 담습니다.
4. **중단**: 측정 중지 시 현재 시도의 입력을 버립니다. 불편하거나 아프면 ‘중단’을 눌러 즉시 멈추세요. 시작음이 아직 확인되지 않았다면 저장할 결과를 만들지 않습니다. 시작음 이후 중단했다면 이미 두 번 확인한 범위만 결과로 보여주며, 사용자가 저장해야 적용됩니다.
5. **결과**: 시작음과 주파수, 최저/최고 편안음, 전체 범위, 추천 연습 음역을 표시합니다. 좌우로 움직일 수 있는 피아노 건반에서 전체 범위와 추천 범위를 구분합니다.

측정 목표 범위는 C2~E5이며, 기계적으로 끝까지 부를 필요는 없습니다. 목에 힘이 들면 중단하세요. 이 기능은 편안한 노래 연습 범위 안내이며 성부를 베이스/바리톤 등으로 분류하거나 의학적·전문 성악 평가를 하지 않습니다.

### 추천과 4주 과정

추천 범위는 **실제 확인한 최저·최고음**의 중앙을 기준으로 계산합니다. 넓은 범위에서는 양끝을 조금 피하고 최대 7반음의 짧은 범위를 추천하며, 좁은 범위에서는 확인한 음만 사용합니다. G2~E4 등 서로 다른 결과에 동일한 고정 C3~G3 범위를 강제하지 않습니다.

- 1주차: 편안한 범위 중앙 부근의 한 음을 기준으로 따라 부릅니다.
- 2주차: 추천 범위 안에서 서로 다른 2~3개 음을 선택합니다. 한 음만 확인된 경우에는 한 음부터 유지합니다.
- 3주차: 개인 추천 음으로 구성한 8박 패턴을 연습합니다.
- 4주차: 작은별의 음 간격을 유지한 채 전체 음이 편안한 음역 안에 들어오도록 키를 자동 조정합니다. 곡 화면에서 안전한 범위 안의 키를 반음 단위로 변경할 수 있습니다. 확인한 범위가 곡에 필요한 9반음보다 좁으면 전체 곡 재생/따라 부르기를 제한하고 짧은 패턴을 안내합니다. 음을 임의로 접거나 범위 밖으로 강제하지 않습니다.

기준음·음정 트레이너는 개인의 편안한 범위 안에서 목표를 선택합니다. 높낮이 퀴즈도 개인 추천 범위 안에서 출제하며, 한 음만 확인됐다면 두 음 퀴즈를 제한합니다. 결과를 저장하지 않았거나 진단을 건너뛴 경우 기존 C3 기본 연습을 유지합니다. 20분 타이머는 진단을 열 때 일시정지합니다.

### 기록과 설정

음역 결과·과거 이력·허용 오차·초기 안내 설정은 **Preferences DataStore**에 저장합니다. 앱 재실행 시 최신 결과를 불러옵니다. 재측정과 최저/최고음 직접 수정은 기존 결과를 덮어쓰지 않고 새로운 기록을 추가하며, 과거 기록과 현재의 최저·최고음 차이를 비교할 수 있습니다. 수정한 범위도 추천 음·멜로디·키에 즉시 적용합니다. 이전 측정의 시작음은 기록으로 보존하고, 최초 직접 설정의 기준음은 선택한 범위 중앙음임을 표시합니다.

기본 판정 허용 오차는 **±25 cents**이며 설정에서 ±10~100 cents로 바꿀 수 있습니다. 목표음 대비 오차를 계산하므로 다른 음이나 옥타브를 낸 것을 현재 감지음 기준으로 정답 처리하지 않습니다.

### 입력 품질과 안전한 측정

기존 AudioRecord/YIN과 표시 안정화를 재사용하고 분석 범위를 약 60~800 Hz로 확장했습니다. 3초 창에서 신뢰도·RMS를 통과한 유효 입력이 충분해야 하며, 중앙값과 cents 편차로 무음·비주기성 잡음·흔들림·지속되는 옥타브 혼합을 제외합니다. 소수의 이상치는 대표 음을 이동시키지 않습니다. 분석은 UI 스레드 밖에서 실행합니다.

기준음과 진단 마이크는 동시에 동작하지 않습니다. 이전 재생 코루틴을 취소·종료한 뒤 잔향 대기 시간을 두고 측정합니다. 권한 거부, 사용자 중지, 배경 이동, 오디오 포커스 상실 시 측정 중인 창을 채택하지 않습니다. 녹음 파일을 만들거나 전송하지 않으며 DataStore도 클라우드 백업·기기 간 전송에서 제외합니다.

### 추가 검증

기존 테스트와 신규 테스트를 포함해 59개 테스트를 작성했습니다. 순음·고음 확대 범위·무음·신뢰도 낮은 잡음·음정 흔들림·옥타브 혼합·목표 대비 높고 낮은 입력·조정 가능한 오차·중단·권한 거부 후 상태·두 번의 편안함 확인·DataStore 재실행 복원·재측정/수정 이력을 검증합니다. 지원 범위 내 모든 최저/최고 조합에서 추천 음과 패턴이 편안한 범위 안에 있는지도 검사합니다. 실제 Android 권한 창과 물리 마이크/지연은 실기기 확인 항목으로 남깁니다.

이 변경의 Gradle 테스트·lint·APK 검증 결과는 PR과 GitHub Actions 실행 링크에 기록합니다. 터미널의 네트워크 제한으로 로컬 Gradle 다운로드가 차단된 경우 CI에서 같은 명령을 실행합니다.

## 설치

1. [GitHub Actions](https://github.com/JungdongBae/sing/actions/workflows/android.yml)에서 초록색으로 성공한 최신 실행을 엽니다. GitHub 로그인이 필요할 수 있습니다.
2. 실행 하단의 **Artifacts → sing-debug-apk**를 다운로드하고 ZIP을 풉니다.
3. Android 기기로 `app-debug.apk`를 옮겨 엽니다. 파일 관리자 또는 브라우저의 ‘알 수 없는 앱 설치’를 허용하면 설치할 수 있습니다.

APK는 디버그 서명된 설치용 빌드입니다. 스토어 배포용 서명은 포함하지 않습니다. Artifact는 30일 보관되며, 브랜치 push/PR/수동 실행에서 다시 빌드합니다. 최초 PR 워크플로에 GitHub 승인이 필요한 경우 저장소 Actions 화면에서 승인해 주세요.

## 사용 방법

- **오늘**: 4주 프로그램을 확인하고 하루 20분 타이머를 시작합니다. 2분 준비 + 6~8분씩 두 가지 핵심 연습 + 4분 마무리로 구성됩니다. 단계가 바뀌면 현재 할 일과 연습 도구 버튼이 바뀝니다. 주차는 기본적으로 누적 완료일을 기준으로 선택되며 타이머가 멈춘 상태에서 다른 주차를 선택할 수 있습니다.
- **음정**: 목표음은 기본 C3(130.81 Hz), E2~C4에서 반음 단위로 변경합니다. 기준음을 듣고 마이크를 켠 뒤 편안하게 허밍합니다. 현재 음 이름, Hz와 **선택한 목표음 대비** cents를 확인하세요. ±25 cents를 초록으로 표시합니다. 실제 옥타브 차이도 ±1200 cents로 표시합니다.
- **듣기**: 낮은 음역의 두 음을 듣고 두 번째 음이 높은지 낮은지 답합니다. 정답을 보기 전 음 이름을 숨기며 다시 듣기와 다음 문제를 제공합니다.
- **박자**: 50~120 BPM으로 4박자를 반복합니다. 첫 박의 클릭을 강조합니다. 클릭과 동시에 버튼을 누르면 가장 가까운 박 대비 빠름·늦음(ms)을 표시합니다.
- **곡**: 8박 패턴 또는 퍼블릭 도메인인 「작은별」 전체 48박(C3~A3)을 듣고 연습합니다. 따라 부르기는 클릭만 재생하고 재생 위치에 따라 목표음을 바꾸면서 마이크 음정을 표시합니다. 클릭 유입을 줄이려면 이어폰을 사용하세요.
- **기록**: 날짜별 누적 연습 시간과 20분 완료 기록을 확인합니다. 타이머는 사용자가 시작해야 진행됩니다. 다른 도구로 이동해도 타이머가 계속되며, 앱이 배경으로 이동하면 멈춥니다. 20분을 채우면 자동 완료되고 하루 동안 중복 완료는 만들지 않습니다. 미완료 시간도 재시작 후 이어집니다.

## 개인정보와 오디오 처리

- 마이크 권한은 음정 측정 또는 따라 부르기를 누를 때만 요청합니다. 거부해도 기준음·귀 훈련·메트로놈·타이머를 사용할 수 있습니다. 영구 거부 시 앱 권한 설정을 열 수 있습니다.
- 인터넷 권한, 서버, 분석 SDK, 녹음 파일을 사용하지 않습니다. PCM은 메모리에서 분석하고 버립니다. 연습 날짜·시간, 목표음·BPM만 SharedPreferences에 저장합니다. Android 자동 백업을 끕니다. 앱 삭제 또는 데이터 삭제 시 기록이 사라집니다.
- 배경 이동, 오디오 포커스 상실, 사용자 중지 시 AudioRecord와 AudioTrack을 중지하고 코루틴에서 안전하게 해제합니다. Activity 재생성에도 ViewModel이 상태를 유지합니다.
- 입력은 22,050 Hz 우선, 지원하지 않으면 44,100/48,000 Hz로 대체합니다. YIN의 정규화 차분과 첫 주기 최소점, DC 제거, RMS 게이트, 신뢰도 임계값, 포물선 보간, 3프레임 중앙값을 사용합니다. 분석 범위는 약 60~800 Hz입니다.
- 목표음에 가까워 보이게 옥타브를 접지 않습니다. 일시적 옥타브 튐은 중앙값으로 줄이되 지속된 실제 옥타브 이동은 그대로 표시합니다. 배경의 주기적 소리, 약한 기본음, 큰 반주에서는 잘못 감지할 수 있습니다. 조용한 곳에서 한 음을 유지하세요. 음정 표시는 약 0.2~0.3초 지연될 수 있습니다.
- 메트로놈은 AudioTrack의 네이티브 PCM 루프를 사용합니다. 화면 박자는 playback head 기준입니다. 탭 피드백은 기기 출력·터치 지연까지 보정한 전문 측정값은 아닙니다. Bluetooth보다 스피커 또는 유선 이어폰을 권장합니다.

## 개발과 검증

JDK 17, Android SDK 35가 필요합니다. Android Studio에서 열거나 `local.properties`에 SDK 경로를 설정하고 실행하세요. Gradle 8.10.2 공식 wrapper JAR과 배포 ZIP SHA-256 검증을 포함합니다.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

GitHub Actions에서도 같은 명령으로 단위 테스트, Android lint, APK 생성을 실행하고 APK와 검사 보고서를 업로드합니다. 단위 테스트는 저음 순음·강한 2차 배음·잡음/DC·무음·샘플레이트 대체, 옥타브 안정화, 목표음 기준 cents, 높낮이 문제, 박자 오차, 4주/20분 단계와 전체 곡을 검증합니다.

실기기 확인 항목은 [docs/DEVICE_CHECKLIST.md](docs/DEVICE_CHECKLIST.md)를 참고하세요. 실제 마이크·출력 지연·기기별 권한 동작은 JVM 단위 테스트만으로 검증할 수 없습니다.

## 구조

`core/`는 Android와 분리한 음정·음악·훈련/음역 워크플로, `audio/`는 입력과 PCM 재생, `data/`는 기존 연습 기록과 음역 DataStore, `SingViewModel`은 코루틴과 상태, `ui/`는 한국어 Compose 화면과 음역 진단/설정입니다.
