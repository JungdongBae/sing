# 실기기 검증 체크리스트

이 문서는 아직 실행하지 않은 실기기 검증 항목입니다. CI의 JVM 테스트와 lint는 물리 마이크·스피커를 검증하지 않습니다.

- Android 8 이상과 Android 15 이상에서 APK 설치·실행, 큰 글자와 작은 화면에서 스크롤/시스템 바 겹침 확인
- 최초 권한 허용, 거부, 다시 요청, 영구 거부 후 설정에서 복구 확인
- 권한 거부 상태에서 기준음, 귀 훈련, 메트로놈, 타이머 사용 확인
- C3/E2/A3 입력으로 음 이름·Hz 확인, 목표를 D3로 바꿨을 때 C3 입력의 −200 cents 확인
- C4 입력을 C3 목표에 비교했을 때 +1200 cents 확인
- 무음·선풍기·대화 잡음에서 표시 숨김과 다시 목소리를 낼 때 복구 확인
- 기준음 재생과 마이크 사이 빠른 전환, 화면 전환, BPM 연속 변경에서 크래시·중복 오디오 여부 확인
- 홈 버튼, 잠금, 전화/다른 미디어 앱의 오디오 포커스 상실에서 마이크·재생·타이머 중지 확인
- 화면 회전과 백그라운드 복귀 후 진행 시간 보존, 오디오가 자동으로 재시작하지 않는지 확인
- 50/60/120 BPM의 첫 박 강조와 4박 반복, 탭 빠름/늦음 확인
- 짧은 패턴/작은별 듣기와 이어폰으로 따라 부르기에서 화면 목표음이 박자에 맞게 바뀌는지 확인
- 20분 완료 후 같은 날짜 중복 카운트 방지, 앱 종료/재시작 후 미완료 시간과 완료 기록 보존 확인
- 날짜 변경 시 새 날짜의 타이머로 전환하며 전날 기록이 남는지 확인
- 비행기 모드에서 모든 기능 실행 확인

## 개인 음역 진단

- 업데이트 설치 시 기존 날짜별 연습 기록이 남고 첫 음역 안내가 표시되는지 확인
- ‘나중에 하기’ 후 앱을 다시 열었을 때 안내를 반복하지 않고 기존 기능을 사용하는지 확인
- 시작음을 두 번 측정·편안함 확인 후에만 최저음 단계로 넘어가는지 확인
- 한 번만 편안한 낮은/높은 음은 ‘어려움’ 선택 시 음역에서 제외되는지 확인
- 측정 도중 ‘측정 중지’, ‘중단’, 홈 버튼/잠금/전화에서 마이크 표시가 사라지고 중단한 창이 채택되지 않는지 확인
- 기준음 재생 중 측정을 시작할 수 없으며, 재생 종료 후 측정에 스피커 잔향이 섞이지 않는지 확인
- 무음·소음·떨리는 소리·다른 옥타브에서 ‘편안함’ 버튼이 비활성화되고 재측정을 안내하는지 확인
- 결과를 저장하기 전 닫거나 재측정하면 기존 저장 음역이 유지되는지 확인
- 결과 저장/앱 재실행에서 DataStore 이력과 최신 음역이 복원되는지 확인
- 최저/최고음 직접 수정과 재측정이 각각 과거 이력을 남기며 추천 음역과 곡 키를 갱신하는지 확인
- 한 음 또는 좁은 음역에서 패턴이 범위를 벗어나지 않고, 작은별을 담을 수 없으면 제한되는지 확인
- 허용 오차 변경이 진단·트레이너·훈련 안내에 일관되게 적용되는지 확인
- 키를 반음 단위로 바꿔도 작은별의 전체 음이 저장한 편안한 범위를 벗어나지 않는지 확인
- 큰 글자/작은 화면에서 진단 중지 버튼과 피아노 건반 좌우 스크롤, 키보드·설정 메뉴 동작 확인
