# 1.2 한 곡 완성 모드

## 사용 순서

1. 기존 음역 진단 또는 직접 설정을 완료합니다. 이전 기록에는 시작음 검출 신뢰도가 없으며 새 진단에서 저장합니다. 중앙 추천 범위는 실제 최저/최고에서 계산한 범위입니다.
2. 상단 ‘나의 첫 완성곡’에서 적법하게 보유한 MIDI/MusicXML을 가져옵니다. 단선율 파트와 출처, 실제 옛사랑 멜로디·마디·템포·길이를 직접 확인합니다. 앱은 원곡 일치를 자동 인증하지 않고 ‘사용자 확인 기준자료’로 표시합니다.
3. 키 후보를 골라 같은 어려운 구간을 각 키로 녹음하고 자가 평가를 합니다. 모든 후보를 비교한 후 최종 키를 결정합니다.
4. 기준음 → 멜로디 → 허밍 → ‘아’ → 보유한 가사 → 녹음 → 결과 → 반복 순서로 연습합니다. 실제 가사는 앱에 없습니다.
5. 각 주차의 20분을 완료하고 숙련을 별도로 자가 확인합니다. 필요하면 현재 주차를 반복합니다. 완료율은 연습 이력이며 노래 숙련 점수가 아닙니다.
6. 선택 키로 만들어진 반주와 멜로디 자료의 시작 시각을 확인하면 전체 반주 녹음을 합니다. 앱은 반주 피치를 변경하지 않습니다.

파일 없이 발성/호흡/발음/강약/프레이징 안내, 자유 녹음·듣기·5항목 평가, 기존 메트로놈을 사용할 수 있습니다. 자체 생성 발성 패턴은 옛사랑이 아니며 객관적인 곡 점수를 만들지 않습니다.

## 훈련 계획 — 각 5일

| 주차 | 1일 | 2일 | 3일 | 4일 | 5일 |
| --- | --- | --- | --- | --- | --- |
| 5주 | 감상·구간·기준 녹음 | 가사 리듬·박자 | 키 후보 비교 | 첫 구간 허밍 | 후렴·최종 키 |
| 6주 | 첫 구간 음정 | 첫 구간 박자 | 후렴 음정 | 취약 구간 반복 | 구간 연결·녹음 |
| 7주 | 허밍·편안한 발성 | 호흡·긴 구절 | 발음·전달 | 음량·프레이징 | 녹음·표현 비교 |
| 8주 | 전체 연결 | 반주 연습 | 전체 녹음·평가 | 부족 구간 교정 | 최종 녹음·비교 |

매일 3분 준비 + 5분 음정/박자 + 8분 노래 + 4분 녹음/비교입니다. 기초 타이머와 동시에 세지 않고, 배경에서 멈춥니다. 날짜·주차·일차·반복 회차별로 미완료 시간도 저장합니다. 다음 일차에는 완료와 숙련 자가 확인이 모두 필요하지만 원하는 주차/일차를 직접 선택해 연습할 수도 있습니다.

## 지원하는 곡 자료

- MIDI: 형식 0/1, PPQ 타이밍, 전역 템포 변경, Note On/Off, running status, 트랙·채널 선택. 타악기 채널 제외. SMPTE/형식 2는 거부합니다.
- MusicXML: 압축하지 않은 UTF-8 `score-partwise`, 음 높이·쉼표·마디·박자표·성부·붙임줄, 파트 간 공유 `sound tempo`. 표준 외부 DOCTYPE 선언을 제거한 후 읽고 외부 자료를 가져오지 않습니다. 인라인 엔티티는 거부하고 가사 태그는 저장하지 않습니다.
- 한 파트에서 동시에 울리는 음, 압축 MXL, 반복/도돌이표/구조 이동, 꾸밈음, 미분음, 이조 악기의 비실음 표기는 지원하지 않습니다. 단선율 실음으로 변환하고 반복을 펼쳐 가져오세요.
- MIDI/MusicXML 2MB·10분 이하. 템포가 없으면 기본 120 BPM임을 경고하고 직접 확인합니다. MIDI 박자표가 없으면 마디는 4/4 기준임을 알립니다. 기준 키가 없거나 바뀌면 원키를 추정하지 않고 파일 기준 반음 이동량으로 표시합니다.
- 4마디 묶음을 자동 구간으로 만들고 사용자가 첫 구간/후렴 등 이름을 정합니다. 실제 구조를 추측하지 않습니다. 자료 적용 전에는 이전 곡을 유지합니다.
- 반주는 기기에 복사해 오프라인으로 재생하며 100MB·10분 이하입니다. 선택 키와 같은 반음 이동량 및 같은 시작 시각을 사용자에게 확인받습니다. 반주 파일의 실제 키나 타이밍을 자동 인증하지 않습니다.

## 추천과 평가의 의미

파일 기준 -24~+24반음 중 곡의 모든 음이 편안한 최저~최고 안에 들어오는 키만 허용합니다. 노트 지속시간과 등장 횟수에 가중치를 주고 추천 중앙 범위와의 거리·음역 양끝의 부담을 함께 고려해 최대 3개를 제안합니다. 어떤 후보도 없으면 적합한 키가 없다고 표시합니다.

같은 구간의 모든 후보를 실제 녹음한 비교 자료가 필요합니다. 유효 음성 70% 이상이어야 비교하고, 목표 허용오차 맞춤 비율 50% 이상·편안함 4/5 이상인 키만 음정 70% + 편안함 30%로 최종 선택합니다. 조건을 충족하는 후보가 없으면 선택하지 않습니다. 재진단 후 이전 프로필의 녹음을 키 선정에 섞지 않습니다.

YIN 검출의 실제 샘플 시각을 사용하고 분석은 UI 밖에서 실행합니다. 표시용 평활화로 분석을 늦추지 않습니다. 신뢰도/RMS를 통과한 음성만 쓰고 이웃 음으로 소수 옥타브 이상치를 완화하되 실제 옥타브 차이는 유지합니다. 목표음이 아닌 감지음의 최근접 음을 기준으로 정답 처리하지 않습니다. 공격/끝 부분을 제외한 음성 확보와 목표 허용범위 비율을 구분하며, 부분 녹음의 미측정 시간을 정답 처리하지 않습니다.

‘음정 안정도’는 목표 허용범위 안의 비율이며 음색·표현력 점수가 아닙니다. 기준 멜로디나 유효 음성이 없으면 점수를 만들지 않습니다. 박자는 지연 보정이 있어야 구분 가능한 발성 시작점의 ±120ms 비율로 표시하며, 구분할 수 없는 반복음 시작점은 제외합니다.

클릭 4번의 마이크 도착 시각으로 지연을 추정하거나 확인한 -500~500ms 값을 직접 입력합니다. 연결된 장치 목록이 바뀌면 보정을 해제합니다. 같은 목록에서 활성 출력 경로만 바꾸면 감지가 제한되므로 직접 다시 보정해야 합니다. 스피커 잔향/소음/Bluetooth/물리 기기에서 추정 정확도는 아직 검증하지 않았습니다. 마이크와 출력의 지연 보정은 전문 녹음 장비 수준을 보장하지 않습니다.

## 녹음과 저장

사용자가 버튼을 누를 때만 권한을 요청하고 3초 준비 후 WAV를 내부 저장소에 씁니다. 구간/전체는 멜로디 끝에서 자동 종료하며 자유 녹음 최대 10분입니다. 중단·배경·포커스 상실 시 마이크를 해제하고 0.3초 이상 부분 녹음을 표시해 저장합니다. 권한 거부/준비 중 취소 시 생성하지 않습니다. 강제 프로세스 종료로 미완료 임시 파일을 복구하지 않습니다.

`CompletionStore`(Preferences DataStore): `SongMetadata`, `MelodyNote`, `SongSection`, 선택 키·프로필 ID, `KeyTrial`, 날짜/주차/일차/회차 `PracticeSession`, `RecordingSession`, `PerformanceReport`, `VocalSelfAssessment`, 지연값·연결 장치 정보, 로컬 반주 메타데이터. 기존 `RangeStore`와 `PracticeStore`를 유지합니다. 새 시작음 신뢰도는 호환 가능한 음역 codec v2에 저장하고 v1도 그대로 읽습니다.

자가 평가는 편안함·호흡·발음·연결·듣기 만족도 1~5점입니다. 같은 구간/키/프로필/허용오차/보정 조건의 녹음만 수치로 비교하고 다른 조건은 별도 이력으로 남깁니다. 음색과 표현은 듣고 판단합니다. 파일/자가 평가/키 비교 기록을 삭제할 수 있습니다.

인터넷 권한·서버·외부 전송 기능이 없으며 파일과 DataStore는 백업/기기 간 전송에서 제외합니다. 앱 삭제/데이터 삭제 시 녹음과 기록도 사라집니다. 공개 개발용 고정 디버그 서명을 유지해 1.1→1.2 덮어 설치가 가능하도록 구성했습니다. 최초 1.0의 임시 서명과는 호환되지 않습니다.

## 아직 검증하지 않은 부분

단위 테스트와 GitHub Actions로 구조·알고리즘·저장·APK를 검증합니다. 실제 권한 창, 오디오 장치 중단, 물리 마이크, 파일 선택기, 스피커/이어폰 지연, 적법한 옛사랑 자료의 완곡 타이밍 및 사용자 학습 효과는 실기기 검증이 필요합니다. 원곡 키/음역을 검증하거나 실제 음색 개선을 입증한 기능으로 표현하지 않습니다. 세부 항목은 [DEVICE_CHECKLIST.md](DEVICE_CHECKLIST.md)에 있습니다.
